# 🎸 My Songbook - by UX_Amix

Una Single Page Application (SPA) diseñada para músicos, cantantes y bohemios que necesitan su repertorio siempre a la mano. Este MVP fue construido con un fuerte enfoque en **UX/UI**, **Accesibilidad (WCAG)** y adaptación al **Contexto de Uso**.

## ✨ Features (Sprint 1)
- **Gestión Local:** Base de datos persistente (`localStorage`) con CRUD completo desde un Admin Panel oculto.
- **Smart Sorting & Filtros:** Sistema de segmentación (Originals/Covers) y ordenamiento algorítmico (Most Played 🔥 y Favoritos ❤️).
- **Motor de Acordes:** Detección automática de acordes con modal de diagramas para guitarra.
- **Transposición Musical:** Ajuste de tono (+½ / -½) en tiempo real.
- **Accesibilidad y Contexto:** Controles dinámicos de tamaño de fuente (A+/A-) diseñados para la *Thumb Zone* móvil y legibilidad a distancia.
- **Dark Mode:** Transición fluida de temas para escenarios con poca iluminación.

## 🛠 Tech Stack
- HTML5, CSS3 (Vanilla)
- JavaScript (ES6+)
- Arquitectura SPA sin frameworks.
